# The Perception Gap

An 8-question interactive for **Global Migration 101, Module 2: Migration Data and Global Trends** — students guess the real numbers behind global migration (scale, geography, money), then see how their instincts compare with the data. Every figure is cited to UN DESA, UNHCR, or the World Bank via the Module 2 lecture.

Part of **Refugees & Migrants in Our Common Home** (migrationandacademia.org).

- `index.html` — the game (single self-contained page; no accounts, no tracking, nothing stored)
- `teachers.html` — passcode-gated Teachers' Area: facilitator guide, class-mode instructions, discussion questions, LMS embed code, answer map
- `downloads/perception-gap-scorm12.zip` — SCORM 1.2 package (reports completion on launch)

## Publishing

GitHub Pages: Settings → Pages → Deploy from a branch → `main`, `/ (root)`.

## Updating the figures

All questions, answers, explanations and sources live in the `ROUNDS` array at the top of the script in `index.html`. Data vintage matches the Module 2 lecture: UN DESA International Migrant Stock 2024, UNHCR Global Trends 2025 (end-2024), World Bank/KNOMAD 2024, Remittance Prices Worldwide Q4 2023.

## Accessibility

Zero axe-core WCAG 2.1 A/AA violations across all game states at mobile and desktop widths; fully keyboard-operable; respects reduced-motion preferences.

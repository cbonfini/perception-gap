Perception Gap BuilderMake your own guess-the-number game — no coding, nothing stored on a server
How this works
  1. Fill in the game settings and add questions. Each question needs the wording, a slider range, and the true data answer. Context, explanation and source are optional but make the reveal much stronger.
  2. Preview to play what you've built.
  3. Download the game file — a single self-contained HTML page you can host anywhere (GitHub Pages, an LMS file upload, a shared drive) or send to colleagues. Or, if this builder is hosted on the web, copy a share link — the whole game travels inside the link itself.
  4. Export questions (JSON) to save your work; import the file later to edit when the data changes. Nothing is saved in the browser — export before you close the tab.

Game settings

Questions

Slider games work best with 5–10 questions. Set the slider maximum well above the true answer so guesses have room to run high — that's where the interesting gaps show up.

Prefer working in a spreadsheet? Download the Excel template or the CSV template, fill in one row per question, and import it here. Importing replaces the questions currently in the builder.
